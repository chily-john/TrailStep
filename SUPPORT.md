# Support

TrailStep is maintained part-time. The best support channel depends on what you need.

## Questions and usage help

Use GitHub Discussions if enabled. If Discussions are not available, open an issue with the `question` label.

## Bugs

Open a bug report and include:

- TrailStep package/version
- Node and pnpm versions
- operating system
- reproduction steps
- expected behavior
- actual behavior
- logs or error output when safe to share

## Feature requests

Open a feature request with the problem you are trying to solve, not only the implementation you want. Maintainers may redirect feature requests to fit the project roadmap.

## Security reports

Do not open public issues for vulnerabilities. See [SECURITY.md](SECURITY.md).
