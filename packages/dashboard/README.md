# @stepkit/dashboard

`@stepkit/dashboard` is not part of the initial public publish set.

This workspace package currently contains a Svelte/Vite observability UI for local StepKit run artifacts. It lists run directories under `.stepkit/runs`, summarizes status from persisted events, and streams run events through a read-only development-server API.

Do not install it as a published npm package yet; inspect `.stepkit/runs` artifacts directly or use the CLI commands from `@stepkit/cli` for the initial release.
