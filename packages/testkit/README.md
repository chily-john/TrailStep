# @stepkit/testkit

`@stepkit/testkit` is not part of the initial public publish set.

This workspace package currently contains internal testing utilities for StepKit workflows and packages. It is intended for validating observable workflow behavior, prompt rendering, runtime events, and failure paths while StepKit's public testing surface is still being finalized.

Do not install it as a published npm package yet; use the public packages `@stepkit/core`, `@stepkit/authoring`, `@stepkit/cli`, and `@stepkit/create-flows` for the initial release.
